# 兵锋未至 · Before the Onslaught

原创 Roguelike 王国构筑策略游戏：通过卡牌经营经济、布置建筑与军队，以自动战斗抵挡敌对势力，在奖励中形成不同构筑，最终挑战 Boss 并完成征服。

从主菜单选择三波「鸦渡防线」或六波「灰旗远征」。远征加入军令商店、生产与军粮、建筑升级、远程和辅助兵种，并以断桥元帅决战收尾。

通关鸦渡防线后，点击「前往灰旗远征」即可选择王国。远征的前两波会指出暂时没有防御塔覆盖的渡口，并提供布阵提示。

远征有部队可出阵时，「守军阵势」会按当前波次和所选阵势提示何时可守住东岸、恢复主动迎击或收缩到城堡附近。最终波可尝试「收缩内线」，在城堡附近拦截随后入场的裂岩巨兽。选择会延续到下一波，也可以在备战时手动调整。

「元帅的最后通牒」中，断桥元帅在开战后 3.3 秒入场，三只裂岩巨兽从 11.5 秒起分批接近战线。备战时点击敌军名可查看其数量、首次入场时间和能力。

开战后，左侧按兵种显示在场和待入场的敌军。点击在场兵种可定位一名单位，重复选择可切换同类敌军。也可选中地图上的单位或建筑。右侧显示当前生命、耐久或能力，地图标记会跟随选中的单位。

标准与简化动效都会显示伤害和治疗数字。同一批落在同一位置的同类数字合计显示，后续数字会尽量与仍在屏幕上的数字错开。简化动效下，范围攻击以静态圆环显示实际伤害范围。

本地启动见[启动与检查](#启动与检查)。离线试玩可双击 `build/Nine Kingdoms.html`。用 `npm.cmd run build:playtest` 可从当前源码生成该文件。[试玩说明](docs/PLAYTEST.md)

网页静态包使用 `npm.cmd run build` 生成。发布脚本可检查托管地址的文件与缓存，也可在原地址实际更新后验证旧档续玩。 [静态网页发布说明](docs/DEPLOYMENT.md)

GitHub 仓库可直接连接 Cloudflare Workers Builds。构建命令用 `npm run build`，部署命令用 `npx wrangler deploy`。 [Cloudflare Workers 设置](docs/DEPLOYMENT.md#cloudflare-workers)

网页主菜单可在战场加载期间使用。若提前进入备战，开战按钮会等战场就绪后启用。战场加载失败时，可按备战界面的提示重新加载页面，再从原有检查点继续。

主菜单的「进度备份」可导出当前检查点和远征纪事。换试玩包路径、浏览器或电脑后，打开新版游戏并导入同一个 JSON 文件即可恢复。确认前可比较备份与本机进度。若另一标签页期间有更新，游戏会刷新摘要并等待再次确认。 [迁移步骤](docs/PLAYTEST.md#换设备或试玩包时迁移进度)

本机保留一个可续玩的战局。已有存档时，开始新局会显示原战局和新战局的摘要，可以替换，也可以选「临时试玩」并保留现有进度。浏览器存储不可用时，主菜单可直接开始临时试玩。临时战局运行到关闭、刷新或返回主菜单为止，结算可以下载战报。

波次战报会按敌军种类显示城堡实际失去的生命和命中次数，方便复盘主要威胁。战斗失守时还能查看最后一次攻击的位置。战利品和胜负界面的「保存战报」可以下载本波明细。胜负结算的「保存整局战报」会汇总当前战局留存的波次、军令选择和战后布局。

用键盘领取战利品后，焦点停在刚加入手牌的军令。可以先查看并安排下一波部署，再选择「开始战斗」。

备战时，点击左侧作战简报的敌军名称，可查看本波数量、首次入场时间、基础属性和特殊能力。黑旗精锐的破甲和断桥元帅的半血反击也列在这里。

远征起初可选钢铁、奥术、自然和战争，分别侧重城墙与步兵反击、魔法塔火力、食物生产和骑兵动员。钢铁步兵在存续栅墙周围获得护甲，可还击射程内的近战敌人。战争王国的骑兵冲锋会波及目标周围 1.5 格内的其他敌军，骑兵每波也少用一份食物。主菜单的「远征纪事」记录功勋，达到里程碑会解锁额外开局军令、擅长远射的潮汐王国和占卜传承。远征结算显示本次解锁与下个目标。

达到 9 功勋后可在开局选择「占卜传承」，从第一批战利品起就能花费 3 魔力换一组。它与月环祭坛共用每局一次的占卜机会。

第 4 波备战的沿途事件会额外提供一件由种子决定的遗物。打开事件可比较两件遗物和免费补给，本波开战前可选一项。

选中征兵建筑可查看并高亮实际出阵位置。兵营、弓营和骑营的相邻空地影响出阵数。若两个营地争用一格，游戏会尝试把有其他空地的部队调开，让更多部队有位置出阵。备战面板会列出仍受阻的营地，点击可直接定位。部署或迁移的落点预览会指出哪些营地将获得或失去出阵位，以及计入产出和费用后有多少部队能出阵。

布置或迁移会阻挡行军的建筑时，地图用青色实线标出预计的新路线。通路封闭时，标记会停在预计破障的格子，并显示该建筑的名称。交战中的追击和攻击可改变敌军行动。

鸢尾矛兵可从相邻斜格拦截敌军，攻击无视护甲。图鉴可查看它的 1.5 格基础射程。

标准动效下，鸢尾矛兵按移动距离循环行走，在实际出手时伸矛并收回戒备。兵营征召的矛兵和召唤出的矛灵共用这套动作。

备战时，作战简报显示各渡口所在行，以及有几座防御塔能打到桥中央。选中防御塔军令或开始迁移时，将鼠标移到候选格，或用方向键定位，即可在落点预览看见覆盖会怎样变化。

灰旗远征的北岭、南岭外营分别在第 2、4 波备战时开放。紫色菱形表示灵脉，月环祭坛可建在灵脉上并强化紧邻的法师塔与魔法塔。祭坛存续时可付出 3 魔力更换整组战利品，每局一次。主菜单和战局设置中的「图鉴」可按名称或能力浏览军令、建筑、兵种、王国、遗物和科技。

战斗中按 Esc 或点击「暂停战斗」可打开暂停菜单。返回主菜单后从本波备战继续。设置支持音量、静音、试听和三档动态效果。主菜单的「退出游戏」会离开当前页面。

切换标签、最小化浏览器或把焦点移到其他窗口时，战斗自动停住并静音。回到游戏窗口后继续进行。手动打开的暂停菜单需要点击「继续战斗」。

设置中的「帧率上限」可选 30、60、120、144 FPS 或「跟随屏幕」，默认为「跟随屏幕」。切换立即生效并随设置保存。实际帧率取决于屏幕刷新率、浏览器和设备性能。「标准」动态效果在模拟步之间平滑显示单位移动和弹道。

设置中勾选「战报附上帧率」后，打完一局即可从整局战报查看各波采样。已完成波次的采样随检查点保留。 [实机采样步骤](docs/PLAYTEST.md#实机性能采样)

战场、军令和图鉴共用原创像素图集。[战场与军令截图](docs/screenshots/phase4-atlas-deployment.png) · [图集制作记录](assets/originals/nine-kingdoms/PROVENANCE.md)

标准动效下，边境卫士、雾林弓手、赤鬃骑兵都会按移动距离播放六帧步态。弓手松弦和骑兵冲锋在实际出手时开始播放。开发服务器的 `/tools/guard-motion.html` 可对照整身逐帧与关节动画导出方案。[卫士动作制作记录](assets/prototypes/guard-motion/README.md)

断桥元帅有专属行进、挥剑和半血砸地动作。半血震击发生时，战况提示和音效同时触发。地面的范围环对应实际伤害半径，简化动效保留静态范围环，关闭动效时保留文字提示。

标准动效下，黑旗精锐按移动距离播放六帧行进，在实际近战出手时播放战镐前刺，停步后以收势姿势戒备。

白铃治疗师成功回血时会起手，并用绿色弧线指出受治疗的单位。根语召唤师成功呼出矛灵时会施法，紫色轨迹指向实际出场格，同时播放召唤音效。简化动效保留静态落点标记。

## 开发方向

- 目标：Windows 上的现代桌面浏览器，鼠标操作和窗口缩放。
- 技术：TypeScript 5.9.3、Phaser 3.90.0、Vite 6.4.6、HTML/CSS、本地 JSON、Vitest 3.2.7，依赖由锁文件固定。
- 运行：不依赖在线服务器，资源全部本地化；安装依赖与正常游玩的网络需求分开处理。
- 原创：仅参考类型理念，实际内容、代码和视觉自主制作或合法授权。

## 启动与检查

在项目目录中使用 Node.js 22.12.0 或更高版本。Windows PowerShell 可使用 `npm.cmd` 避开本地的脚本执行策略。

首次安装依赖或锁文件更新后，先关闭正在运行的开发和预览服务，再执行以下命令。

```powershell
npm.cmd ci
npm.cmd run dev
```

依赖已装好时，日常启动只需 `npm.cmd run dev`。Windows 重装依赖时如果提示 `EPERM` 且路径指向 `esbuild.exe`，在本项目运行 Vite 的终端按 `Ctrl+C`，等开发和预览服务退出后重试。npm 的全局缓存目录若不可写，可用 `npm.cmd ci --cache .npm-cache`。

打开终端显示的本地地址，默认是 <http://127.0.0.1:5173/>。正常游戏所需资源全部在本地。

点击「开始部署」，选择军令，然后点击地图上的河东草地。可用「选建造军令」切换可负担的建筑，或按数字键选牌，Esc 取消。悬停箭塔或部署位置可查看射程。左侧简报列出本波敌军编成，右侧显示选中建筑或单位的属性。开始战斗后守军自动攻击，可暂停观察。本波结束后选择战利品，继续部署。维修法术和资源战术可在备战时直接点击使用。

选中建筑军令后，地图下方会预览落点占地，以及对产出、出阵位置和法术塔伤害的影响。用数字键或手牌上的 Enter 选择需要落点的军令，焦点会进入地图。方向键选格，Enter 确认，Esc 返回手牌。放错建筑或集结点时，开战前点击右侧的「撤销部署」。每次撤回最近的一项，原军令和部署费用会返还。若返还后超过仓储上限，先花掉一些库存。开战会确认本波部署，升级或使用研究所时也会确认相关部署及其之前的部署。新版备战存档会保留可撤销记录。

备战时，点击任意已部署的建筑或集结点，可以在详情栏迁移。建筑迁移消耗 1 木材，保留原等级和耐久。集结点迁移消耗 1 食物。资源不足时会当场提示。迁移采用相同的占地和地形规则，按 Esc 可取消。迁移后仍可撤销本波尚未确认的部署，已付迁移费计为消耗。

要腾出地块，可以点击「拆除」或「解散」。最近一项符合撤销条件的部署会在窗口显示「撤回并返还」，同时列出返还费用。选择「确认拆除」或「确认解散」会腾出地块，原军令和资源计为消耗。拆除仓库前若库存超过拆除后的容量，需先腾出相应库存。撤回、迁移和拆除完成后都会自动保存。

战后「本波战况」会列出出阵数、缺粮队伍与位置受阻数，失守时显示最后一次攻击的来源或战斗超时。刷新后从战利品界面继续时仍可查看该波战报。

有军队时，备战栏的「军粮分配」会列出开战可用食物、每处集结点和征兵建筑的位置、每支成本及预计出阵数。若调整优先级会影响出阵，先展开条目下的预览，查看全军耗粮和各支部队的人数变化。可以选一处优先供给，再按原顺序配给其他部队。设置会保存并保留到后续波次，再点已选项可恢复默认。

远征备战可在「守军阵势」切换主动迎击、固守东岸或收缩内线。后两档分别以第 5 列河岸和第 7 列内线为迎击边界，地图会显示阵线。前置部队仍可攻击射程内的敌军。阵势会随备战存档保存，并保持到下一波备战。

「灰旗远征」第 3 波起，军令商店每波常备一张「河畔农圃」。购入需要 2 金币，落地另需 2 金币和一块合法土地。临水部署的一级农圃会在开战前产出 3 食物，自然王国另有加成。

每波备战抽两张战术牌。它们在使用或开战时进入弃牌堆，牌库空了就把弃牌洗回。战后选中的战术可立即使用，并加入之后的循环。建造和招募军令用后消耗，未用的可以保留。

远征种子会改变桥位和部分敌军编成。第 2、4 波备战可从沿途事件中选补给或付费购买遗物，遗物栏能查看持续效果。

远征首波可点「查看战术牌」，查看手牌、牌库和弃牌中的张数。首波过后，「整理战术牌」会显示强化后的牌名、效果和费用。强化或移除按手牌、牌库、弃牌的顺序处理同名牌中的一张，整理后至少保留两张战术牌。

部署后可点击研究所，在射程、军粮和城墙维护三项科技中选一项。英雄厅每波召集渡桥誓卫。兵营贴栅墙、弓营贴兵营、骑营贴英雄厅分别增加出阵名额。多一支队伍就要多留相应的空位和军粮。

默认种子 119，可在选关时手填或点击「随机种子」。灰旗远征会在开局前显示种子对应的路线。远征结算选择「换种子再出征」，可沿用当前王国和已解锁传承，预选一个新种子。要复盘原局，可选「重开同一战局」。

种子控制奖励抽取，同样的部署和奖励选择可以复现战局。备战进度与战利品会自动保存在当前浏览器，刷新后从主菜单选择「继续战局」。战斗中刷新会回到本波开战前。若提示「进度尚未保存」，可在备战或战利品界面重试。音效和减少动态效果设置独立保存。

主存档损坏时，游戏会尝试读取备份，并在主菜单提示。确认从备份继续后，主存档会恢复。两份存档都无法读取时可主动开始新战局。

开发版可在主菜单选择战役、王国和种子，再点击「打开调试沙盒」。沙盒允许补满库存、跳到指定备战波次、加入指定军令、安排指定敌军、暂停时钟后推进模拟，以及调整单个场上单位的属性。在沙盒里结束战役或修改设置都不会改动正常存档、功勋和设置。退出页面会结束本次沙盒会话。

浏览器帧和内存的采样命令、环境及结果见 [远征运行性能记录](docs/PERFORMANCE.md)。

完整远征可通过生产包重放。先运行 `npm run build`，再设 `NINE_KINGDOMS_PRODUCTION=1` 并运行 `npm run test:browser:kingdoms -- iron`。浏览器选择、帧率采样和低速运行命令见 [生产包复测](docs/PERFORMANCE.md#生产包复测)。

远征中，点击已部署的建筑查看产出、耐久和升级费用。双仓粮栈向右占两格。开战先结算产出，再按优先设置及默认顺序支付军粮。简报会显示实际参战数。商店购买军令只支付购入费用，部署时另付卡面费用。当前可试玩的内容与阶段验收见 [开发进度](progress.md)。
