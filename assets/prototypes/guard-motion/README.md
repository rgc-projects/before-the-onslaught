运行 `npm.cmd run dev` 后，访问终端地址下的 `/tools/guard-motion.html`。可切换绘制上限和同屏人数，也可下载两个 288 × 44 的透明图集。对照页把两套动作各预生成六帧，播放时走相同 Canvas 图集流程。

Edge 在同页每侧 40 名卫士的样稿上实测到约 120 FPS，60 档同样生效。两套动作都在画布中产生可观测的姿势变化。这个样稿的 Canvas 提交时间无法代表包含地图、AI、弹道和特效的完整战斗。整身方案在当前尺寸下腿部轮廓更清楚，关节方案能直接改腿、剑和盾的角度并再次导出。整身方案用于首个战场单位，关节样稿保留供多个相近兵种共用动作时比较。
