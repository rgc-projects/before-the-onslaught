## 实施前需要作出的专业判断

以下通常可由开发 Agent 为当前阶段选择合理基线并记录，不必逐项等待用户确认：

- 地图尺寸、可建区域、城堡位置、敌人入口、解锁方式。
- 首轮基础建筑/卡牌/兵种子集与开局资源；完整清单不得删除。
- 单局目标波次、奖励节奏、Boss 机制和可复现种子方案。
- 视角、像素尺寸、调色板、单位锚点、UI 实现方式与本地字体。
- 备战/战斗中允许的操作、资源结算时机和食物维持规则。
- 堵路/不可达目标、攻击优先级、停滞战斗的合法处理。
- 存档时机、战斗中保存策略、迁移与调试隔离。
