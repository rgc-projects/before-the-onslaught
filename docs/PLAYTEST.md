# 兵锋未至 0.1.0 试玩

《兵锋未至》是一款王国构筑策略游戏。你会决定如何布阵、经营和选牌，守军随后自动迎敌。

## 开始

如果收到的是可打开的游戏地址，直接用桌面浏览器打开。使用新版压缩包时，先解压到一个文件夹，再双击 **Nine Kingdoms.html**。也可以在浏览器按 Ctrl+O，选择这个文件。游戏的图像和音效已经打包在文件里，断网也能玩。

离线文件沿用原文件名，便于覆盖原位置并读取进度。日常续玩可以用同一个浏览器打开原位置的文件，点击「继续战局」。

战利品或备战界面若提示「进度尚未保存」，请先点击「重试保存进度」。看到「进度已保存」后再刷新或关闭页面。

已有进行中的战局时，点击「开始部署」会先显示原战局和新战局。想保留旧局又要试另一战役，在确认窗口选「临时试玩」。如果浏览器禁止本地存储，可以在主菜单选「开始临时试玩」。临时战局的进度只在当前页面有效，刷新、关闭或返回主菜单会结束本局。结算时可下载战报。

若远征结算提示功勋保存失败，可在结算页点击「重试保存功勋」。如果已经关闭游戏，可从主菜单继续上一次成功保存的检查点，重新打完该波。

功勋已记入远征纪事时，这场远征已完成，可以直接开始新局。备份会保留已获得的功勋。

同一浏览器的多个标签页共用一个战局存档。如果收到另一标签页已更新战局的提示，可在主菜单点击「继续战局」载入较新的进度。同一场远征的功勋以较新的战局进度结算为准。

### 换设备或试玩包时迁移进度

1. 在原路径打开游戏，从主菜单进入「进度备份」，点击「导出进度」，保存 JSON 文件。
2. 打开新的试玩包，从「进度备份」选取刚导出的文件。对照「待导入」和「本机当前进度」的战局与功勋，再点击「确认替换本机进度」。若提示本机进度已有更新，先核对更新后的摘要，再决定是否确认。
3. 返回主菜单。如果备份里有战局，点击「继续战局」。

从还没有「进度备份」入口的旧包升级时，先用原来的浏览器打开同一路径、同文件名的新版 HTML，再导出进度。

### 含有 dist 文件夹的旧试玩包

如果手里的压缩包提供的是 `dist` 文件夹，请解压后在该解压目录打开 PowerShell。已有 Python 3 的 Windows 电脑可以运行以下命令。

```powershell
py -3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

保持 PowerShell 窗口开启，结束后按 Ctrl+C。[打开本机试玩页面](http://127.0.0.1:8080/)

## 试玩顺序

1. 从主菜单进入「鸦渡防线」，按自己的理解游玩，直到出现胜利或失守结算。
2. 胜利后点击「前往灰旗远征」。如果失守，可以重试，也可以返回主菜单选择「灰旗远征」。任选一个王国并尝试一局。
3. 如果时间允许，再试一次。记下你主动改变的一项部署、选牌或资源计划。

想在同一张地图复盘，可以选「重开同一战局」。想尝试另一套开局，可以在远征结算选「换种子再出征」，查看新种子对应的路线，再决定是否开始部署。

使用键盘时，可按数字键选军令。进入地图后用方向键选格，地图下方会显示落点预览。按 Enter 确认，按 Esc 返回手牌。用键盘领战利品时，焦点会移到新军令，方便继续备战。

浏览器跟随 Windows 对比度主题时，落点实线框表示能部署，虚线框表示不能部署。地图格子的无障碍名称会包含已有建筑或备战集结点的名称。

备战的「军粮分配」中，展开「优先后全军出阵」可先看耗粮和受影响的部队。点「优先供给」才保存选择。处于优先状态的部队也可预览取消优先后的变化。

交战时，左侧按兵种显示在场和待入场数量。点击在场兵种，或用 Tab 聚焦后按 Enter，可定位一名单位。再次选择同一兵种会切换到下一名在场单位。也可点击地图上的格子查看详情，标记会跟随选中的单位。

在标准或简化动效下，同一批落在同一位置的伤害数字会合计显示，治疗量以「+」显示。简化动效用静态圆环标出范围攻击的实际范围。

## 实机性能采样

在需要验收的 Windows 电脑上打开此试玩包。在「设置」勾选「战报附上帧率」，选定帧率上限和动效后开始战斗。比较设备时可用 60 FPS 上限与标准动效作为同一套设置。

打到胜负结算后点击「保存整局战报」。文本末尾按波次列出实际绘制帧率、帧间隔 P95、超过 50 毫秒的次数和采样时长。只查看当波时，也可以在战利品或结算界面点击「保存战报」。

暂停与切后台会断开计时。改变帧率上限、动效或窗口尺寸会分开统计。已完成波次的摘要随检查点和进度备份保留，刷新续玩后仍可导出。取消勾选会停止采样，并在新导出的战报中隐藏已记录的帧率。

提交实机反馈时，可附整局战报并注明浏览器版本、CPU、显卡和内存。请重点记录第 2、5、6 波遇到的卡顿。比较帧率时请使用相同动效档。

## 反馈

「设置」下方可查看构建版本，例如 `0.1.0+6ceae2227419`。单波和整局战报都会附上导出时的构建版本。只发截图时，可以一并提供设置里显示的版本。

在胜负结算中点「保存整局战报」，把已记录的波次放进一个文本。文件里有种子、王国、每波军粮、城堡损伤、领取的军令和战后保留的建筑。中途刷新续玩会保留已记录的波次。若由旧版存档继续，文件会提示是否缺少早期波次。

只提交其中一波时，可在「选择战利品」点「保存战报」。你可以先打开文本确认内容，再与试玩反馈一起发送。
